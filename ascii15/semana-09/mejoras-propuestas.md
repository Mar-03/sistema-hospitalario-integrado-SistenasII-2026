# Semana 9 - Mejoras propuestas

## 1. Prioridad alta

- Representar `409` como alerta clinica critica.
- Indicar explicitamente que la prescripcion no se guardo.
- Marcar campos obligatorios.
- Usar mensajes especificos por contexto.
- Diferenciar excepcion autorizada de una accion normal.
- Asociar `403` a `reason` y `authorized_by`.

## 2. Prioridad media

- Agregar ayudas para `dose` y `frequency`.
- Mejorar jerarquia de botones.
- Conservar datos tras error en una futura UI.
- Usar lenguaje menos tecnico que codigos HTTP.
- Dejar `date` claramente como opcional.

## 3. Dependencia futura

- Catalogo de pacientes.
- Catalogo de medicamentos.
- Catalogo de medicos/autorizadores.
- Autenticacion para identificar al medico.
- Consulta previa de alergias.
- Historial/listado de prescripciones.

Estas mejoras requieren endpoints o integraciones futuras. No se implementan en Semana 9.

## 4. No alcance

Semana 9 no trabaja:

- Frontend real.
- Backend.
- API nueva.
- Responsive o mobile.
- Alta fidelidad.
- Branding, colores finales o tipografias finales.
